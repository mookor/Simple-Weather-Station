# 🌡️ Simple Weather Station

Умная метеостанция на базе **WEMOS D1 Mini (ESP8266)** с датчиком **DHT11**, **OLED дисплеем** и **Telegram ботом** для удаленного мониторинга температуры и влажности.

## 🚀 Установка

### 1. Установка Arduino IDE

Скачайте и установите [Arduino IDE](https://www.arduino.cc/en/software)

### 2. Настройка ESP8266 в Arduino IDE

1. Откройте **File → Preferences**
2. В поле **Additional Board Manager URLs** добавьте:
   ```
   http://arduino.esp8266.com/stable/package_esp8266com_index.json
   ```
3. Откройте **Tools → Board → Boards Manager**
4. Найдите и установите **esp8266** by ESP8266 Community

### 3. Установка библиотек

Откройте **Sketch → Include Library → Manage Libraries** и установите:

- `DHT sensor library` by Adafruit
- `Adafruit GFX Library` by Adafruit
- `Adafruit SSD1306` by Adafruit
- `FastBot` by AlexGyver

**ESP8266WiFi** и **Wire** уже включены в пакет ESP8266.

### 4. Загрузка проекта

1. Клонируйте или скачайте проект
2. Откройте `Simple_Weather_Station.ino` в Arduino IDE
3. Выберите плату: **Tools → Board → ESP8266 Boards → LOLIN(WEMOS) D1 R2 & mini**
4. Выберите порт: **Tools → Port → COMX** (ваш порт)

## ⚙️ Настройка

### 1. Создание Telegram бота

1. Найдите бота [@BotFather](https://t.me/BotFather) в Telegram
2. Отправьте команду `/newbot`
3. Следуйте инструкциям и получите **токен бота**

### 2. Настройка config.h

Откройте файл `config.h` и измените следующие параметры:

```cpp
// ===== НАСТРОЙКИ WiFi =====
const char* WIFI_SSID = "ВАШ_SSID";           // Имя вашей WiFi сети
const char* WIFI_PASSWORD = "ВАШ_ПАРОЛЬ";     // Пароль WiFi

// ===== НАСТРОЙКИ TELEGRAM БОТА =====
#define BOT_TOKEN "ВАШ_ТОКЕН_БОТА"  // Токен от @BotFather
```

### 3. Настройка пинов (при необходимости)

Если ваше подключение отличается, измените пины в `config.h`:

```cpp
#define DHTPIN D3       // Пин подключения DHT11
#define SCREEN_ADDRESS 0x3C    // Адрес I2C дисплея (0x3C или 0x3D)
```

## 🎮 Использование

### Загрузка на плату

1. Подключите WEMOS D1 Mini к компьютеру
2. Нажмите **Upload** (стрелка) в Arduino IDE
3. Дождитесь завершения загрузки

### Первый запуск

После загрузки программы:

1. Откройте **Serial Monitor** (Tools → Serial Monitor, 115200 baud)
2. Устройство подключится к WiFi
3. В Serial Monitor отобразится IP адрес
4. На OLED дисплее появится индикация "Bot OK!"
5. Найдите вашего бота в Telegram и отправьте `/start`

### Мониторинг

- **OLED дисплей** показывает текущие данные в реальном времени
- **Telegram бот** позволяет получать данные удаленно
- **Serial Monitor** выводит отладочную информацию

## 🔌 Схема подключения

### DHT11 → WEMOS D1 Mini

| DHT11 | WEMOS D1 Mini |
|-------|---------------|
| VCC   | 3.3V          |
| GND   | GND           |
| DATA  | D3 (GPIO0)    |

### OLED 128x64 (I2C) → WEMOS D1 Mini

| OLED  | WEMOS D1 Mini |
|-------|---------------|
| VCC   | 3.3V          |
| GND   | GND           |
| SCL   | D1 (GPIO5)    |
| SDA   | D2 (GPIO4)    |

## 📊 Технические характеристики

- **Интервал измерений**: 30 секунд (настраивается в config.h)
- **Диапазон температуры DHT11**: 0-50°C (±2°C)
- **Диапазон влажности DHT11**: 20-90% (±5%)
- **Разрешение OLED**: 128x64 пикселей
- **WiFi**: 2.4 GHz (802.11 b/g/n)
- **Питание**: 5V через USB или 3.3V

## 🛠️ Решение проблем

### Дисплей не работает

- Проверьте I2C адрес (может быть 0x3C или 0x3D)
- Используйте I2C сканер для определения адреса
- Проверьте подключение SDA/SCL

### DHT11 выдает ошибки

- Убедитесь, что датчик подключен правильно
- Проверьте правильность пина в config.h
- Датчику нужно 1-2 секунды для инициализации

### WiFi не подключается

- Проверьте правильность SSID и пароля
- Убедитесь, что роутер работает на 2.4 GHz
- Проверьте силу сигнала

### Telegram бот не отвечает

- Проверьте правильность токена
- Убедитесь, что WiFi подключен
- Проверьте Serial Monitor на наличие ошибок
